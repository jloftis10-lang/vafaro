# Vafaro

Vafaro is a trip-fit and travel-friction checker. It helps families understand whether a beautiful itinerary will actually work for the real people taking it.

## Local development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## MVP experience

- Premium, responsive landing page
- Four-step Trip Check intake
- Sample Trip Fit Report
- Transparent source-confidence language
- Human-review upsell and workflow concept

The current report is a polished product prototype. A production release should connect the assessment to live place, routing, weather, accessibility, and AI services, then persist reports and reviewer actions in a database.
